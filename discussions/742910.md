# Clarification: Does the Task 2 timestamp cutoff apply to external data?

https://www.kaggle.com/competitions/2026-ieee-big-data-traffic-flow-bench/discussion/742910

**Henrique José De Souza** (2026-09-24T03:02):

Hello,

For Task 2, the organizer response in discussion 742068 states that no data timestamped after T may be used “in any file.” Does the timestamp <= T restriction also apply to publicly available external datasets or APIs, or only to the competition’s released files?

We can proceed without external data, but this clarification would help ensure that our method is compliant and reproducible.

Thank you.

---

**Traffice_Flow_Bench_Organizer** (2026-09-28T18:00):

Good question. The timestamp rule applies to the competition's released files, since those are the only place the state of these corridors after T could come from.

External datasets and APIs are governed by the External data section of the Rules instead. The released records are synthetic and the calendar matches no real period, so a window's T does not correspond to any real date, and no external source contains the state of these corridors after it. You may use public external data under the usual conditions, and disclose it if you reach the finals.

The one limit that applies regardless of source is the existing prohibition on any resource whose purpose is to identify the hidden answers.
