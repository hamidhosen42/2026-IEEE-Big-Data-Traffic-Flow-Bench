**Traffice_Flow_Bench_Organizer** (2026-09-09T22:59):

Submissions are paused while we fix a flaw in the released data. This affects everyone, including Tasks 1, 3 and 4, so please read on even if you have not worked on Task 2.

A participant reported that the forecast horizon of every Task 2 window was also published as an observation in mainline_states_masked, on both scored splits. We confirmed it. About 67 percent of Task 2 target cells on validation carried an observed speed, and applying the published queue cutoff to those observations scores S_queue 0.641 against 0.252 for the persistence baseline, with no forecasting involved. The original report is here:

https://www.kaggle.com/competitions/2026-ieee-big-data-traffic-flow-bench/discussion/740522

This is a flaw in how we built the release, not an ambiguity in the rules. We are sorry. Anyone who has been building a genuine forecasting method for Task 2 has been competing against a shortcut we left open, without knowing it was there. That is our mistake.

What we are doing. We are blanking the horizon cells in the released state files, using the same four channels the Task 1 mask already blanks, so that after the fix none of the Task 2 target cells carry an observation. The state files therefore change, and so does the observation grid the Task 3 physics score is built from.

Two things this means for you, and we are sorry for both:

You will need to download the data again. The state files change. sample_submission.csv, submission_key.csv and every submission_id stay exactly the same, so anything you have keyed on those still works.
Submissions made before the fix will not count toward the final standings. The shortcut was open the whole time submissions have been running, and we have no way to tell which submissions used it. Resetting everyone is the only even-handed option we have.

We expect this to take several hours. We will post here as soon as submissions are open again.

Thank you to Luigi Ishii for finding this and for reporting it instead of using it.
