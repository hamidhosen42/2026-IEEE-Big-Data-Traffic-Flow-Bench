# সেরা উপস্থাপনের বংশধর (tfb-g4 , পাবলিক LB  0.88092 = চূড়ান্ত প্রার্থী A)

2026-10-06 থেকে কেগল kernel মেটাডেটা ( `kernelDataSources` ) থেকে ট্র্যাক করা হয়েছে, `tfb-g4` থেকে শুরু করে।
-67 kernelগুলি অ্যাক্সেসযোগ্য। সম্পূর্ণ গ্রাফটি `lineage_g4.json` এ রয়েছে এবং প্রতিটি কার্ণেলের সঠিক উত্সটি `lineage_src/<slug>.py` এ রয়েছে।
- এই kernelের অধিকাংশই স্কেপ বা কম্পোজিট ধাপ। প্রতিটি ধাপ কিছু সারি প্রতিস্থাপন করে এবং বাকিগুলোকে একা রেখে যায়।
- নীচের টেবিলটি দেখায় যে কোন kernel শেষ পর্যন্ত প্রতিটি ব্লক রং তৈরি করেছে। এই kernelগুলি একক-প্রবেশ স্ক্রিপ্টের পুনরায় প্রজনন করতে হবে।

- নিয়মঃ এক এন্ট্রি স্ক্রিপ্ট প্লাস README এবং পরিবেশ। সংগঠকরা এটি পুনরায় চালান, এবং এটি তার ব্যক্তিগত স্কোরের 1 % এর মধ্যে নির্বাচিত জমা পুনরায় প্রজনন করতে হবে।
